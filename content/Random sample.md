# Random sample

A [[Random sample]] is a collection of observable random variables $X_1,\ldots,X_n$ that are iid from a common distribution.

It is the default data structure for [[Sampling distribution]], [[Maximum likelihood estimator]], and [[Hypothesis test]] problems.
