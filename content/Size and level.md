# Size and level

Size and level both constrain the [[Power function]] on the null parameter space.

A size $\alpha$ test satisfies

$$\sup_{\theta\in\Theta_0}\beta(\theta)=\alpha.$$

A [[Level alpha test]] satisfies

$$\sup_{\theta\in\Theta_0}\beta(\theta)\le\alpha.$$

Size uses the full Type I error budget. Level only requires staying within it.
