# Hypothesis test

A [[Hypothesis test]] is a rule that maps data $X=(X_1,\ldots,X_n)^T$ to a decision about rejecting [[Null hypothesis]].

The rule can be represented by a [[Test function]]. In non-randomized form, it is determined by a [[Rejection region]] and an [[Acceptance region]].
