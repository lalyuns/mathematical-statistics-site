# Acceptance region

The [[Acceptance region]] is the complement of the [[Rejection region]].

[[Test inversion]] reads acceptance regions in reverse: fixed parameter values give tests, while fixed data values give a [[Confidence set]].

Related: [[Non-randomized test]], [[t confidence interval]].
