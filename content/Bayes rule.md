# Bayes rule

If $A_1,\ldots,A_n$ partition $\Omega$ and $P(B)>0$, then

$$
P(A_i\mid B)=
\frac{P(B\mid A_i)P(A_i)}
{\sum_{j=1}^n P(B\mid A_j)P(A_j)}.
$$

[[Bayes rule]] rewrites posterior probabilities using likelihoods and prior probabilities.

Related: [[Conditional distribution]], [[Bayes estimator]].
