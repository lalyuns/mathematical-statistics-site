# Power function

For a [[Test function]] $\varphi$, the [[Power function]] is

$$\beta(\theta)=E_\theta[\varphi(X)].$$

For a [[Non-randomized test]], this is $P_\theta(X\in C)$, where $C$ is the [[Rejection region]].

On $\Theta_0$, $\beta(\theta)$ is the [[Type I error]] probability. On $\Theta_A$, it is [[Power]].
