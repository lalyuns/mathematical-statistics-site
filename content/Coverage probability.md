# Coverage probability

[[Coverage probability]] is $P_\theta(\theta\in C(X))$, the probability that a random [[Confidence set]] contains the true parameter.

A confidence coefficient takes the worst case over parameter values.

Related: [[Confidence set]], [[Test inversion]].
