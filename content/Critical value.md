# Critical value

A [[Critical value]] is the threshold that turns a test statistic into a [[Rejection region]].

It is usually chosen so the test has the desired [[Size and level]].

Related: [[Non-randomized test]], [[Likelihood ratio test]], [[t confidence interval]].
