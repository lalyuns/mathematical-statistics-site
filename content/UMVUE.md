# UMVUE

A [[UMVUE]] is an unbiased estimator with minimum variance among all unbiased estimators of the same target.

There is no uniformly minimum MSE estimator without constraints, because bias and variance trade off differently at different parameter values. The course therefore restricts attention to unbiased estimators.

Key tools for finding it are [[Rao-Blackwell theorem]], [[UMVUE characterization]], and [[Lehmann-Scheffe theorem]].
