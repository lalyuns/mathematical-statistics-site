# Simple hypothesis

A simple hypothesis fixes a parameter at one value, such as $H_0:\theta=\theta_0$.

[[Neyman-Pearson lemma]] is a theorem for simple null versus simple alternative. When a hypothesis contains many parameter values, it is a [[Composite hypothesis]].
