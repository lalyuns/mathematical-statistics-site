# Randomized test

A [[Randomized test]] can reject with probability strictly between 0 and 1 at some sample points.

Randomization is useful at boundaries, where a test must hit an exact size. [[Boundary randomization]] is the version used in [[Neyman-Pearson lemma]].

Related: [[Test function]], [[Size and level]].
