# Test function

A [[Test function]] gives the rejection probability at each sample point:

$$\varphi(x)=P(\text{reject }H_0\mid X=x).$$

If $\varphi(x)=1(x\in C)$, the test is a [[Non-randomized test]]. If $\varphi$ can take values between 0 and 1, it is a [[Randomized test]].

[[Power function]] is the expectation of the test function under a parameter value.
